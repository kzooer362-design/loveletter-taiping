# 情书：掌上明珠

一款基于经典桌游「情书 Love Letter」改编的在线卡牌对战游戏，支持 2~4 人本地 AI 对战与远程联机对战。

## 游戏简介

在宫廷之中，你是一位追求太平公主的求婚者。通过智慧与策略，运用 8 种不同身份的卡牌，淘汰竞争对手或凭借手中最大的底牌赢得公主的芳心 Token。先集齐目标 Token 数者获胜。

### 卡牌一览

| 点数 | 名称 | 数量 | 效果 |
|------|------|------|------|
| 1 | 金吾卫 | 5 | 猜测目标手牌（不能猜金吾卫），猜中则目标淘汰 |
| 2 | 方士 | 2 | 查看目标玩家手牌 |
| 3 | 宰相 | 2 | 与目标比拼手牌，点数低者淘汰 |
| 4 | 宫女 | 2 | 获得保护，直到下回合不受攻击 |
| 5 | 皇子 | 2 | 目标弃牌并重新抽牌（弃太平公主则死） |
| 6 | 皇帝 | 1 | 与目标交换手牌 |
| 7 | 女官 | 1 | 同时持有皇帝或皇子时必须打出 |
| 8 | 太平公主 | 1 | 弃掉太平公主立即淘汰 |

### 胜利条件

| 玩家数 | 目标 Token 数 |
|--------|--------------|
| 2 人 | 7 |
| 3 人 | 5 |
| 4 人 | 4 |

## 快速开始

### 本地 AI 对战

直接用浏览器打开 `index.html`，点击「开始游戏」→ 选择对手数量和 AI 难度 → 开始对局。

### 联机对战

根据需求选择版本：

- **互联网对战**：使用 `index.html` 或 `index-internet.html`
- **局域网对战**：使用 `index.html` 或 `index-lan.html`

#### 互联网对战（PeerJS 房间号）

1. 房主打开页面 → 联机对战 → 互联网模式 → 创建房间，获得 6 位房间码
2. 朋友打开同一页面 → 联机对战 → 互联网模式 → 加入房间 → 输入房间码
3. 房主选择 NPC 数量 → 开始游戏

#### 局域网对战（WebSocket 服务器）

1. 安装 [Node.js](https://nodejs.org/) 16+
2. 在项目目录执行：
   ```bash
   npm install ws
   node lan-server.js
   ```
3. 终端会打印本机局域网 IP（如 `ws://192.168.1.20:8787`）
4. 房主：联机对战 → 局域网模式 → 服务器地址填 `ws://127.0.0.1:8787` → 创建房间
5. 朋友（同一局域网）：服务器地址填 `ws://房主IP:8787` → 输入房间码 → 加入房间
6. 房主选择 NPC 数量 → 开始游戏

> 自定义端口：`node lan-server.js --port=9999`

## 布局说明

- **16:9 横屏**：适合桌面显示器，左侧日志栏 + 中央对手/牌库/手牌分区
- **9:16 竖屏**：适合手机，垂直分区排列
- 点击右上角 `⛶` 按钮随时切换两种布局

## 技术栈

- 纯 HTML/CSS/JavaScript 单文件应用，无需构建
- [PeerJS](https://peerjs.com/) — WebRTC P2P 互联网联机
- WebSocket (ws) — 局域网/自建服务器联机
- 房主权威模型：房主运行游戏引擎，客户端仅负责渲染和发送操作
